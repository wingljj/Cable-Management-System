电缆/设备管理系统 Win7 x64 离线部署说明

1. 适用环境
- Windows 7 64 位。
- 本包不能用于 32 位 Windows。
- 程序为离线绿色包，运行时数据库保存在程序目录下的 data\equipment.db。

2. 启动方式
- 双击“启动系统.bat”。
- 也可以直接双击 DapmQt.exe。

3. VC++ 运行库
- 程序目录已附带常用 VC 运行库 DLL。
- 如果 Win7 上仍提示缺少 VCRUNTIME140.dll、VCRUNTIME140_1.dll、MSVCP140.dll 或 api-ms-win-crt-*.dll：
  1) 先安装 _redist\vc_redist_2017_x64.exe。
  2) 如仍不能启动，再安装 _redist\vc_redist_2022_x64.exe。
- 这些安装包都在本离线包内，不需要联网。

4. Excel 导入说明
- 支持 .csv、.xlsx、.xls。
- .csv 和 .xlsx 可直接导入。
- .xls 为 Excel 97-2003 格式，导入时需要内网电脑已安装 Microsoft Excel。
- 电缆台账表头必须包含：编号、始端、终端。

5. 扫码枪使用说明（ZEBRA DS2208）
- DS2208 建议使用 USB HID Keyboard / 键盘输入模式。
- 扫码时先点击电缆管理页的搜索框。
- 勾选“回车加入缓存”后，扫描电缆二维码会自动把对应电缆加入借出/归还缓存栏。
- 勾选“回车后清空”后，每次扫码回车后会自动清空输入框，适合连续扫码。
- 如果扫码枪没有自动回车，请使用 Zebra 官方手册/设置码配置 Enter 后缀。

6. 标签打印说明（ZEBRA ZT210）
- 先在 Windows 7 中安装 ZT210 对应的 Zebra/ZDesigner 打印机驱动。
- 在电缆管理页选中一根或多根电缆，点击“打印标签”。
- 打印对话框中选择 ZT210 打印机。
- 标签尺寸、打印浓度、速度等请在 ZT210 打印机驱动首选项中配置。
- 标签二维码内容为电缆编号，标签文字同时显示编号、始端、终端。

7. 数据备份
- 数据库文件：data\equipment.db。
- 迁移或备份时复制整个程序目录，或者至少备份 data\equipment.db。

8. 常见问题
- 如果提示“无法启动此程序，因为计算机中丢失 api-ms-win-crt-*.dll”，请安装 _redist 目录下的 VC++ 运行库。
- 如果 .xls 导入失败，请确认该电脑安装了 Microsoft Excel，并且文件不是损坏的旧版 Excel 文件。
- 如果 .xlsx 导入失败，请确认第一张工作表的表头为“编号、始端、终端”。
- 如果无法打印，请确认已安装 ZT210 驱动，并且程序目录中存在 Qt5PrintSupport.dll。
