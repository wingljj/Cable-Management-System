电缆/设备管理系统 Win7 x64 离线部署说明

1. 适用环境
- Windows 7 64 位。
- 本包不能用于 32 位 Windows。
- 程序为离线包，运行时数据库保存在程序目录下的 data\equipment.db。

2. 启动方式
- 双击“启动系统.bat”。
- 也可以直接双击 DapmQt.exe。

3. VC++ 运行库
- 本包内带有 vc_redist.x64.exe。
- 如果 Win7 提示缺少 VCRUNTIME140.dll、VCRUNTIME140_1.dll、MSVCP140.dll 或 api-ms-win-crt-*.dll，请先运行 vc_redist.x64.exe 安装运行库。
- 安装包在本离线包内，不需要联网。

4. Qt DLL 说明
- 本包使用 Release 程序和 Release Qt 运行库。
- 程序应查找 Qt5Sql.dll，不应查找 Qt5Sqld.dll。
- 如果仍提示缺少 Qt5Sqld.dll，说明使用了旧的 Debug 包，请删除旧目录后重新解压本包。

5. Excel 导入说明
- 支持 .csv、.xlsx、.xls。
- .csv 和 .xlsx 可直接导入。
- .xls 为 Excel 97-2003 格式，导入时需要本机已安装 Microsoft Excel。
- 电缆台账表头必须包含：编号、始端、终端。
- 可选表头：使用期限、备注。
- 使用期限可填写 yyyy-MM-dd，也可只填年份。
- 编号重复时会更新始端、终端，不会重复插入；导入文件包含“使用期限”或“备注”表头时，也会同步更新对应字段。

6. 扫码枪说明
- ZEBRA DS2208 建议使用 USB HID Keyboard / 键盘输入模式。
- 扫码借出/扫码归还请使用电缆管理页中的“扫码借出”“扫码归还”按钮。
- 主界面搜索框也支持“回车后清空”和“回车加入缓存”。

7. 标签打印说明
- ZEBRA ZT210 需要先在 Windows 7 中安装对应 Zebra/ZDesigner 打印机驱动。
- 如果点击打印无反应，请确认程序目录中存在 Qt5PrintSupport.dll 和 printsupport\windowsprintersupport.dll。
- 新标签使用更小二维码和更大文字；新生成二维码内容为电缆编号，旧二维码格式仍可扫码识别。
- 电缆管理页支持“批量打印选中”和“打印当前结果”。
- 电缆台账使用期限可在选中多条电缆后通过“批量改期限”统一修改。

8. 电缆逾期说明
- 电缆管理页状态筛选可选择“逾期未还”。
- 统计分析页包含电缆逾期未还清单。
- 逾期规则：电缆借还记录为“借出中”，且预计归还日期早于当前日期。

9. 数据备份
- 数据库文件：data\equipment.db。
- 迁移或备份时建议复制整个程序目录，或至少备份 data\equipment.db。
